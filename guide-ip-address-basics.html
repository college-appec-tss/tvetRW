IP addresses explained simply

An Internet Protocol (IP) address is a logical address used to identify an interface on an IP network. It helps network traffic reach the correct destination.

IPv4 example

An IPv4 address is commonly written as four decimal numbers separated by dots, such as 192.168.1.20. Each number is between 0 and 255.

Private and public addresses

Private IPv4 ranges are used inside local networks and are not routed directly across the public internet. A public IP address is globally routable, subject to network configuration.

What is a default gateway?

A default gateway is usually a router interface that a device sends traffic to when the destination is outside its local network.

Practice

On a computer you are allowed to use, view its network settings. Identify the IPv4 address, subnet mask and default gateway. Do not change network settings unless you understand the effect or have permission.
