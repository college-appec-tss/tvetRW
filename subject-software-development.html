SUBJECT

Software development

Software development is the process of planning, creating, testing and maintaining software. Start with problem-solving and programming fundamentals, then practise by building small applications.

Suggested learning path

  1. Understand algorithms, flowcharts and pseudocode.
  2. Learn variables, data types, conditions, loops and functions.
  3. Build web pages with HTML and CSS.
  4. Add interactivity with JavaScript.
  5. Learn how a backend, API and database work together.
  6. Test your project and document how it works.

Beginner guides

  • What is HTML?
  • SQL basics

Practise by building a personal portfolio, a simple calculator or a small record-management application using sample data.
