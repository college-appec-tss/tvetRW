# Rwanda TVET Student Hub

A mobile-responsive, static learning resource website for TVET students in Rwanda.

## Flat file structure
All website files are in this single root folder. There are no nested asset or page folders.

## Publish
This build is configured for GitHub Pages at:

https://college-appec-tss.github.io/tvet/

Repository: `college-appec-tss/tvet`

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Push the contents of this folder directly to the repository root.

If you deploy to a different domain or Render URL, replace the canonical and Open Graph URLs in every HTML file, plus the sitemap and robots.txt, with that real public URL before submitting the site to Google Search Console.

## SEO setup
- Unique page titles and meta descriptions
- Canonical URLs and social sharing metadata
- Sitemap and robots.txt
- Semantic page headings and internal links
- Structured data on the homepage and calculator pages
- Responsive layout and lightweight local CSS/JavaScript

## Important before launch
- Update the contact page's placeholder email address.
- Verify all educational content against current Rwanda TVET course materials.
- Add genuinely useful original lessons and exercises regularly.
- Connect Google Search Console, submit `sitemap.xml`, and inspect key pages.
- Do not use copied notes, keyword stuffing, or artificial backlinks.

## Local preview
Run `python3 -m http.server 8000` from this folder and open `http://localhost:8000`.

## Traffic target
100 Google clicks per day is a goal, not a guaranteed outcome. Ranking depends on content usefulness, search demand, competition, authority, indexing and time.
