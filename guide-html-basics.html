What is HTML? A beginner's guide

HTML means HyperText Markup Language. It describes the structure and meaning of content on a web page. A browser reads HTML and uses it to display headings, paragraphs, links, images and other elements.

HTML elements

Most HTML elements have an opening tag, content and a closing tag. For example, a paragraph uses the <p> element.

<p>I am learning HTML.</p>

A basic HTML document

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>My first page</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>I am learning web development.</p>
</body>
</html>

What to practise

  1. Create a file named index.html.
  2. Add one main heading and two paragraphs.
  3. Add a link to another page you created.
  4. Open the file in a browser and inspect the result.
Remember: HTML provides structure. CSS controls presentation, while JavaScript adds behaviour.

Check your understanding

In your own words, explain the difference between an HTML tag and an HTML element. Then create a page about a subject you are studying.
