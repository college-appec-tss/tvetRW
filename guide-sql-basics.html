SQL basics: tables, rows and queries

SQL (Structured Query Language) is used to define, read and change data in relational database systems. A relational database stores related information in tables.

Tables, rows and columns

A table is made of columns (fields) and rows (records). For example, a fictional students table could contain student_id, first_name and programme.

Keys

A primary key uniquely identifies a row in a table. A foreign key refers to a key in another table and helps represent a relationship.

Your first query

SELECT first_name, programme
FROM students;

This query returns the selected columns for rows in the students table. To filter results, use a WHERE condition.

SELECT first_name
FROM students
WHERE programme = 'Software Development';

Practice task

Using a fictional dataset, write a query that selects all columns from a table named courses. Then write another query that selects only courses in a chosen department.

Use fictional records when practising. Do not publish real learners' private information.
