SUBJECT

Database systems

A database stores organised information so it can be searched, updated and managed reliably. Relational databases organise data into tables connected by relationships.

Core concepts

  • Tables, rows and columns.
  • Primary keys and foreign keys.
  • One-to-one, one-to-many and many-to-many relationships.
  • SQL commands such as SELECT, INSERT, UPDATE and DELETE.
  • Validation, backups and access control.

Start with SQL basics: tables, rows and queries. Use a small fictional school database for practice, not real student personal information.
